Vision-guided 6-DOF pick-and-place robot

A color-sorting robot built on a Yahboom DOFBOT arm. The system locates objects in the camera image, maps them into workspace coordinates, and executes each pick-and-place move through geometric inverse kinematics.

2.8 mmMean camera-to-workspace calibration error

Implementation

  • Perception. HSV thresholding segments target objects by color, AprilTag fiducials fix the workspace reference frame, and a planar homography maps image pixels to workspace coordinates.
  • Communication. The host streams XYZ targets to the Jetson over a TCP socket on port 5000, keeping vision processing separate from motion control.
  • Motion. The Jetson solves geometric inverse kinematics for each target and drives the arm’s servos through the pick-and-place sequence.
  • Calibration. Camera-to-workspace calibration reached a mean error of 2.8 mm.

IoT, agriculture

Smart greenhouse monitoring and control

A two-node wireless system for greenhouse automation. A field node handles sensing and actuation inside the greenhouse; a control hub runs the control logic, serves the dashboard and sends alerts.

2 × ESP32Field node and control hub, linked over ESP-NOW

Implementation

  • Field node. ESP32 #2 samples air temperature and humidity (DHT22), light level (LDR) and soil moisture, and switches fans, pumps and grow lights through relay outputs.
  • Wireless link. Node and hub exchange readings and commands over ESP-NOW, Espressif’s low-latency, connectionless peer-to-peer protocol.
  • Control hub. ESP32 #1 runs the system logic and serves an HTML/CSS/JavaScript dashboard over Wi-Fi.
  • Alerting. A Telegram bot notifies operators as soon as a reading breaches its threshold.

Industrial automation, machine safety

Industrial conveyor safety system

Conveyor monitoring that combines PLC-based hardware interlocks with a computer-vision detection layer. Either layer can shut the conveyor down.

< 50 msEmergency-stop response

Implementation

  • Control and interlocks. A Siemens S7-1200 PLC, programmed in TIA Portal with ladder logic, manages emergency-stop logic, motor control and the light curtains, with safety relays in the stop chain.
  • Vision layer. A parallel OpenCV pipeline on an embedded industrial PC detects human proximity, foreign-object intrusion and belt misalignment using edge detection and motion analysis.
  • Redundancy. The two layers operate independently, so a fault detected by either one shuts the conveyor down. Emergency-stop response is under 50 ms.
  • Operator interface. An HMI panel shows live system status and keeps an event log.
